# PDFリーダー

GitHub Pagesで動作する、ブラウザー内処理のPDFリーダーです。PDFをアップロードせず、文字情報のあるPDFをリフロー表示または元のページ表示で読めます。

## 機能

- PDFを選択してブラウザー内で読み込み
- スマートフォン向けのリフロー表示（ページごとに縦読み）とページ表示
- 文字サイズ変更、ページ移動、本文検索
- PDFの内容をサーバーへ送信しない設計

## 制限

- PDF.jsをCDNから読み込むため、初回利用時はインターネット接続が必要です。
- OCRには対応していません。テキスト情報がないスキャンPDFからは本文を抽出できません。
- PDFの段組み、表、脚注などは読み順が正しく復元されない場合があります。元のレイアウトは「ページ表示」で確認できます。

## GitHub Pages

リポジトリの **Settings → Pages** で `master` ブランチの `/(root)` を公開元に設定してください。`index.html` が公開ページとして表示されます。
